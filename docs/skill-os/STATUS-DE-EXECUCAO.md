## Promoção dos pilotos §61 pra `pilot 10%`

- **`SkillOsPilotSeeder.promotePilotsToPilot(10)`** — aplica a decisão do operador de subir os 3 pilotos de `shadow` → `pilot @ canário 10%` (execution_mode `assisted`, cohort-gated). **One-time** via marker de plataforma `pilots_pilot10_v1` (tabela nova `skillos_platform_markers`): aplica UMA vez e nunca re-dispara, então rollback §69 posterior fica de pé. Só **avança** de `shadow`/`development` (preserva skill que o operador já subiu além — nunca rebaixa, nunca mexe no canário dela). Roda no **boot** (após `seedPilots`) + rota manual `POST /api/skillos/promote-pilots { percent? }` (owner/admin). RN-014 respeitado: o sistema não auto-eleva por conta própria — só **aplica** a decisão tomada.
- **`SkillOsPilotSeeder.raisePilotsCanary(p)`** — sobe o canário dos 3 pilotos (não mexe no estágio, só amplia o cohort). Aplicado em degraus `10% → 25% → 50% → 100%`. **One-time por-percentual** (markers `pilots_canary_25_v1`, `pilots_canary_50_v1`, `pilots_canary_100_v1`, …, independentes) e **só sobe**: skill cujo canário o operador já pôs ≥ p é preservada; skill em `shadow` é pulada (percentual não se aplica). Subir só **adiciona** orgs (hash estável — quem estava no balde menor continua); a **100%** o cohort é universal. Boot encadeia os degraus (após `promotePilotsToPilot`) + rota `POST /api/skillos/raise-pilots-canary { percent? }` (owner/admin).
- **Fix RN-RO-5 (não-clobber):** o onboarding (`seedPilots`) roda a cada boot mas o estágio é **estado do operador** — agora semeia `shadow` só na 1ª vez (quando não há linha de rollout) e **nunca sobrescreve** promoção/rollback em boots seguintes. Antes forçava `shadow` todo boot, revertendo qualquer promoção (bug que tornava a esteira não-durável). `SkillOsRolloutService.has()` distingue "nunca configurada" de "development/0".
- `test:skillos-pilot-promote` (22): promoção shadow→pilot@10%, cohort-gated assisted (dentro/fora), one-time (marker), rollback fica de pé, só-avança-de-shadow (preserva operador), onboarding não-clobber, subir canário 10→25% (cohort monotônico, one-time por-percentual, só-sobe, pula shadow), **degraus 10→25→50→100 compõem em sequência com markers independentes; @100% cohort universal**. `test:skillos-pilot-seed` p/ 16 (não-clobber). `tsc` limpo; rollout/registry/resolver/evals verdes — 0 regressão.
